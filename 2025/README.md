# Clean-Code-Cup 2025
Определение строительной готовности : Алтайский государственный университет

Введение
Строительство жилых комплексов (ЖК) — один из ключевых процессов в сфере недвижимости, оказывающий значительное влияние на экономику, бизнес, и повседневную жизнь людей. Для банков, предоставляющих ипотечные кредиты, девелоперов, управляющих проектами, и государственных органов, контролирующих сроки и качество строительства, важно своевременно и точно оценивать прогресс строительства.

Процент готовности объекта — это один из главных индикаторов, позволяющий:

Оценивать риски срыва сроков сдачи жилья.
Контролировать целевое использование инвестиций.
Определять этапы, на которых можно начинать продажи квартир.
Автоматизировать процесс мониторинга крупных строительных проектов.
Сегодня информация о готовности ЖК часто обновляется вручную или с использованием устаревших технологий, что приводит к задержкам, высоким затратам и человеческим ошибкам. Внедрение модели машинного обучения, способной автоматически оценивать процент готовности ЖК по фотографиям, способно значительно упростить этот процесс, сократить издержки и повысить прозрачность.

Постановка задачи
Разработать модель машинного обучения для задачи регрессии, которая на основе одной или нескольких фотографий предсказывает процент готовности ЖК (object) (в диапазоне от 0 до 100%) на конкретную дату (group_id).

О данных
В качестве данных выступают фотографии процесса строительства ЖК с сайта наш.дом.рф. Даные были размечены в полуавтоматическом режиме с использованием LLM и оценкой эксперта на основе фотоографий, даты проведения фотографирования, даты начала строительства и планируемой даты вводы в эксплуатацию.

Важность задачи для бизнеса
Банки и ипотечные организации:

Позволяет оценивать вероятность завершения строительства вовремя, снижая риски дефолтов по ипотеке.
Помогает автоматизировать выдачу траншей по проектному финансированию, основываясь на точных данных о готовности объекта.
Девелоперы и строительные компании:

Позволяет контролировать соблюдение графиков строительства и выявлять потенциальные задержки.
Снижает трудозатраты на ручную проверку строительных объектов.
Государственные органы:

Автоматизирует мониторинг исполнения сроков сдачи жилья в эксплуатацию.
Способствует повышению прозрачности для участников рынка.
Данные
images - архив, содержщий изображения наборов train, test
data.csv - файл, содержащий информацию о проведении фотографического обследования строющегося объекта недвижимости на конкретную дату:

image - имя изображения объекта;
object - uid идентификатор объекта, строящейся недвижимости;
group_id - uid идентификатор проведения фотогографического обследования;
train.csv - файл, содержащий тренировочный набор данных. Иммеет следующую структуру:

object - uid идентификатор объекта, строящейся недвижимости;
group_id - uid идентификатор проведения фотогографического обследования для объекта object_id;
percentage_of_readiness - процент готовности объекта (диапазон 0.0 ... 100.0) таргет.
val_test.csv - валидационный и тестовый набор данных

object - uid идентификатор объекта, строящейся недвижимости;
group_id - uid идентификатор проведения фотогографического обследования для объекта object_id;
percentage_of_readiness - процент готовности объекта (диапазон 0.0 ... 100.0) таргет его необходимо предсказать.
Отправка результатов
Участникам необходимо в качестве ответа отправить csv файл, основанный на val_test.csv путем добавления в него значения целевого столбца percentage_of_readiness - процент готовности объекта строительства. percentage_of_readiness может принимать значение от 0.0 до 100.0.

Оценка алгоритма
Метрикой задачи является MAE. Участники сортируется на лидерборде в порядке увеличения метрики. Во время турнира проверка осуществляется для 50% тестовой выборки. В ходе финального тестирования для выбранных сабммитов, значение MAE будет рассчитано на всех данных тестового набора.
